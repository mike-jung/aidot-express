방명록 API 실습실

aidot-express 에 기본으로 들어 있는 방명록(guestbook) 예제입니다. 설치하고 서버만 켜면 바로 눌러 볼 수 있어요.

서버 주소

이 페이지를 서버에서 열었다면 Base URL 은 비워 두세요. 다른 PC 에서 열었다면 http://서버IP:7901 처럼 적습니다.
기본 경로는 /api/guestbook (기본 예제)입니다. 따라하기 ③ 에서 직접 만든 /api/snacks 나 /api/supplies 로 바꿔서 시험해도 됩니다 — 그때는 아래 [보낼 내용] 칸의 JSON 만 그 API 에 맞게 고치면 돼요.

GET① 글 전체 보기

GET /api/guestbook/

GET② 하나만 보기

GET /api/guestbook/{id}

POST③ 새 글 남기기

POST /api/guestbook/

PUT④ 글 고치기

PUT /api/guestbook/{id}

DELETE⑤ 글 지우기

DELETE /api/guestbook/{id}

서버가 보낸 답 (응답)

아직 요청을 보내지 않았어요.

여기에 결과가 나옵니다.

⑥ 실시간 알림 받기 (SSE)

서버가 먼저 말을 거는 방식이에요. [연결] 을 누른 뒤 위에서 글을 남기거나 지워 보세요 — 방명록이 바뀔 때마다 서버가 알려 줍니다. 이 페이지를 두 개 열어 두면 양쪽에 동시에 나타나요. · GET /api/events/stream?channel=guestbook · POST /api/events/publish
